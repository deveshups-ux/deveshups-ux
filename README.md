## 🚀 Featured Projects

### ⚡ 1. [Kaido — Autonomous Multi-Agent AI Platform](https://kaido-sage.vercel.app) *(Flagship)*
> A production-grade multi-agent orchestration platform delegating queries across **8 specialized autonomous agents** via a **LangGraph** routing engine. Features an in-browser live code execution sandbox, dynamic PDF report compilation with 24h expiring S3 links, and full SaaS credit monetization.

- **Stack:** React 19 · Node.js · Express Gateway · MongoDB Atlas · Redis · LangGraph · Qdrant · AWS S3 · Docker
- 🔗 **[🌐 Launch Live Demo](https://kaido-sage.vercel.app)** &nbsp;·&nbsp; **[📦 View Repository](https://github.com/deveshups-ux/Kaido)**

- **Stack:** React · Node.js · Express · MongoDB · Vector Embeddings · Tailwind CSS
