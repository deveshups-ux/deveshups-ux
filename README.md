## 🚀 Featured Project

### ⚡ [Kaido — Autonomous Multi-Agent AI Platform](https://kaido-sage.vercel.app)

A production-grade, routed multi-agent AI platform — not just a chatbot, but **8 specialized autonomous agents** (Chat, Web Search, Coding Sandbox, Dynamic PDF/PPT generation, Image Synthesis, Vision Analysis, and Vector RAG) orchestrated via a **LangGraph** routing engine. Built with decoupled microservices, in-browser code canvas execution, and real usage quotas.

- 🧩 **Architecture:** Express API Gateway · Decoupled Microservices · MongoDB Atlas Multi-Cluster · Redis Session Cache
- 🤖 **Agentic & RAG:** LangGraph · LangChain · Gemini Embeddings · Qdrant Vector DB · Groq (`gpt-oss-120b`)
- 💻 **Frontend & Sandbox:** React 19 · Vite · Redux Toolkit · Tailwind CSS · Monaco Editor · Live Iframe Preview
- 💳 **SaaS Monetization:** Sliding Rate Limits · Credit Metering · Razorpay HMAC Verification

👉 **[🌐 Open Live Demo](https://kaido-sage.vercel.app)** &nbsp;·&nbsp; **[📦 View Source Code](https://github.com/deveshups-ux/Kaido)**
