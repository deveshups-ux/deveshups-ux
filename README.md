## 🚀 Featured Project

### [Kaido — Multi-Agent AI Platform](https://github.com/deveshups-ux/Kaido)

A routed, multi-agent AI platform — not a single chatbot, but eight specialist agents (chat, live search, coding, PDF/PPT generation, image generation, image understanding, and PDF-based RAG Q&A) behind one LangGraph-powered router. Built with real usage controls: Redis-backed rate limiting, credit-metered usage, and Razorpay billing.

**Stack:** React · Node.js · Express · MongoDB · Redis · LangChain · LangGraph · Qdrant · Razorpay · AWS S3
